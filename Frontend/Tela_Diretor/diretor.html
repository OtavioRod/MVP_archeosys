Bem-vindo, Diretor!

Esta é a tela inicial do sistema ArckeoSys.

Aqui você pode gerenciar todos os Coordenadores Pedagógicos da sua escola. Para isso, utilize os botões do menu acima:

  • 🏠 Início: Retorna para esta tela inicial, onde você pode ler as instruções gerais.
  • 📝 Cadastro: Cadastra novos coordenadores.
  • 📋 Listar: Mostra todos os coordenadores cadastrados.
  • ✏️ Atualizar: Permite alterar os dados de um coordenador existente.
  • 🗑️ Excluir: Remove um coordenador do sistema.

Se precisar sair, clique em ↩️ Voltar ao Login no menu.
